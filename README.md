# Word Quiz

Excel 단어장(단어–뜻)을 SQLite DB로 옮기고, 이를 바탕으로 단어 퀴즈를 반복해 암기를 돕는 개인용 프로그램이다. 첫 지원 언어는 Latin(뜻은 독일어)이다. 로그인·계정은 없고, PC에서 서버를 띄워 브라우저로 쓰며 같은 네트워크의 휴대폰에서도 접속할 수 있다.

## 설치

1. `WordQuiz.zip`을 원하는 폴더에 푼다. **드라이브는 상관없다** — `C:\WordQuiz`, `D:\Apps\WordQuiz`, `E:\WordQuiz` 어디든 된다. 폴더는 **쓰기 가능**해야 한다(첫 실행 때 그 안에 `data\`, `reports\`를 만들기 때문에 `C:\Program Files` 같은 보호된 폴더는 피한다).
2. [Node.js](https://nodejs.org) **22.13 이상**이 PC에 설치되어 있어야 한다(LTS 버전 권장). 이미 설치돼 있으면 이 단계는 건너뛴다.
3. 압축을 풀면 다음 파일들이 있다. `data\`와 `reports\`는 첫 실행 때 자동으로 생긴다.
   ```
   WordQuiz\
   ├─ start.bat      ← 더블클릭해서 실행
   ├─ import.bat      ← 단어장 Excel을 DB로 가져올 때 실행
   ├─ server.mjs
   ├─ import.mjs
   └─ public\
   ```

## 첫 실행

1. Excel 단어장을 준비한다. 첫 행은 헤더이고, 열 이름으로 인식한다.
   - `단어` (필수), `뜻1` (필수), `뜻2`~`뜻4` (있으면 사용), `노트` (선택). 열 순서는 상관없다.
   - 한 뜻 칸에 동의어가 여러 개면 **쉼표**로 구분한다. 괄호 안의 쉼표는 구분자로 보지 않는다(예: `der (die, das) zweite`는 동의어 하나).
   - 뜻 칸에는 `|` 문자를 쓸 수 없다(단어 관리 화면에서 이 문자로 뜻 묶음을 구분하기 때문).
2. `import.bat`을 실행해 DB를 만든다. `import.bat`은 더블클릭이 아니라 **명령 프롬프트에서 인자와 함께** 실행해야 한다.
   - 엑셀 단어장 파일은 어디에 둬도 되지만, 제일 간단한 건 **`import.bat`과 같은 폴더**에 두는 것이다.
   - 그 폴더에서 명령 프롬프트를 열려면: 탐색기로 그 폴더에 들어가서 **주소창을 클릭해 `cmd`를 입력하고 Enter**(또는 폴더 안 빈 곳에서 Shift+마우스 우클릭 → "여기에 PowerShell/명령 프롬프트 창 열기").
   - 엑셀 파일을 다른 폴더에 뒀다면 전체 경로를 따옴표로 감싸 준다. 예: `import.bat "C:\Users\내계정\Downloads\단어장.xlsx" --new-db latin --lang latin`.
   ```
   import.bat "단어장.xlsx" --new-db latin --lang latin
   ```
   기본은 **검증 모드**다. DB를 바꾸지 않고 리포트만 보여 주므로, 먼저 이 상태로 오류·경고가 없는지 확인한다. 문제가 없으면 `--apply`를 붙여 다시 실행해야 실제로 DB에 반영된다:
   ```
   import.bat "단어장.xlsx" --new-db latin --lang latin --apply
   ```
   리포트는 화면에도 나오고 `reports\` 폴더에 파일로도 저장된다.
3. `start.bat`을 더블클릭한다. 콘솔 창이 뜨고 잠시 후 기본 브라우저가 열리며 시작 화면이 보인다. 콘솔에는 접속 주소가 나온다:
   ```
   Word Quiz is running.
     On this PC:  http://localhost:35000
     From a phone on the same network:  http://192.168.x.x:35000
   Close this window or press Ctrl+C to stop.
   ```
4. 시작 화면에서 언어와 방금 만든 DB를 고르면 퀴즈를 시작할 수 있다.

## 단어장을 다시 가져오기(수정·추가 반영)

이미 만든 DB에 Excel의 변경 사항을 반영하려면 `--new-db` 대신 `--db`를 쓴다:
```
import.bat "단어장.xlsx" --db latin --apply
```
- **새 단어**는 추가되고, **뜻이나 노트가 바뀐 단어**는 갱신된다(진행 상태는 그대로 유지된다).
- **Excel에서 지워진 단어는 DB에서 삭제되지 않는다.** 리포트에 "Missing in Excel"로만 표시된다.
- **앱(단어 관리 화면)에서 직접 고친 뜻**이 있다면, Excel의 옛 내용이 다시 그 뜻을 덮어쓸 수 있다. 갱신되는 항목은 리포트에 이전 값과 이후 값이 함께 나오니 반영 전에 확인한다.
- 여러 Excel 파일을 관리한다면 **파일마다 별도 DB**(`--new-db`로 따로 만들기)를 쓰는 것이 자연스럽다. 같은 DB에 다른 파일을 merge하면 첫 파일의 단어가 전부 "Excel에서 사라짐"으로 표시된다.
- 서버가 켜져 있는 동안에도 `import.bat --apply`는 안전하지만, 가능하면 서버를 끄고 반영하는 것을 권장한다.

## 백업

`--db`로 기존 DB에 `--apply`를 반영하기 **직전에** 자동으로 백업이 만들어진다. 위치는 `data\backup\<DB이름>.<날짜-시각>.db`이다. DB를 새로 만드는 `--new-db`는 백업이 필요 없다(아직 아무 내용도 없으므로).

DB 파일(`data\*.db`) 자체가 완결된 백업이기도 하다. 걱정되면 `data\` 폴더 전체를 다른 곳에 복사해 두면 된다(서버가 켜져 있어도 복사는 안전하다).

## 휴대폰에서 접속하기

1. PC와 휴대폰이 **같은 Wi-Fi**에 연결되어 있어야 한다.
2. `start.bat`을 처음 실행하면 Windows 방화벽이 "Node.js가 네트워크에서 이 앱과 통신하도록 허용하시겠습니까?" 같은 창을 띄울 수 있다. **허용**을 눌러야 휴대폰에서 접속된다(사설/홈 네트워크 항목에 체크).
3. 콘솔에 나온 "From a phone on the same network" 주소를 휴대폰 브라우저에 입력한다.
4. PC와 휴대폰에서 번갈아 써도 같은 세션(진행 상황)이 이어진다.
5. 이 PC만 아는 다른 사람에게 노출하고 싶지 않다면, `start.bat --local-only`로 실행해 이 PC에서만 접속되게 할 수 있다(휴대폰 접속은 안 된다).

## 서버 옵션

`start.bat` 뒤에 옵션을 붙일 수 있다(예: 바탕화면 바로가기의 "대상"에 추가). 예: `start.bat --port 36000 --local-only`

| 옵션 | 설명 |
|------|------|
| `--port <숫자>` | 포트 변경 (기본 35000) |
| `--local-only` | 이 PC(`127.0.0.1`)에서만 접속 허용. 휴대폰 접속 안 됨 |
| `--allow-host <이름>` | 그 밖에 허용할 접속 주소(호스트 이름)를 추가. 여러 번 쓰거나 쉼표로 나열할 수 있다(예: `nas.local`) |
| `-h` | 도움말 |

## 문제 해결

| 증상 | 원인·조치 |
|------|-----------|
| 콘솔에 "Node.js was not found" | Node.js가 설치돼 있지 않다. [nodejs.org](https://nodejs.org)에서 설치 |
| 콘솔에 "Node.js 22.13 or later is required" | 설치된 Node.js가 너무 오래됐다. 최신 LTS로 업데이트 |
| 콘솔에 "already in use. Word Quiz may already be running" | 이미 다른 `start.bat`이 실행 중이거나 다른 프로그램이 같은 포트를 쓰고 있다. 기존 콘솔 창을 확인하거나 `--port`로 다른 포트를 쓴다 |
| `import.bat` 실행 후 한글·장음 기호(ā, ī 등)가 깨져 보임 | 콘솔 창 자체의 표시 문제로, `import.bat`은 자동으로 UTF-8(`chcp 65001`)로 맞춘다. 리포트 **파일**(`reports\*.txt`)은 항상 올바른 UTF-8이니 메모장 등에서 열어 확인한다 |
| import 리포트에 "Errors"가 있음 | 반영되지 않는다(검증 모드든 `--apply`든 동일). 리포트에 나온 행 번호와 사유(예: 표제어 중복, 필수 열 없음)를 고쳐 다시 실행 |
| 휴대폰에서 접속이 안 됨 | PC·휴대폰이 같은 Wi-Fi인지, Windows 방화벽에서 허용했는지 확인. 회사·공용 Wi-Fi는 기기 간 통신을 막아 두는 경우가 많다 |
| 프로그램을 새 버전으로 교체하고 싶음 | 서버를 끈 뒤(콘솔 창을 닫거나 Ctrl+C) `start.bat`, `import.bat`, `server.mjs`, `import.mjs`를 새 zip의 것으로 덮어쓰고, **`public\` 폴더는 통째로 지운 뒤** 새 `public\`으로 교체한다(파일명이 바뀌어 옛 파일이 남는 것을 막기 위해). **`data\`와 `reports\`는 그대로 둔다**(지우면 단어장과 학습 기록이 사라진다) |
| 콘솔 창을 실수로 닫음 | 다음에 `start.bat`을 다시 실행하면 이어서 쓸 수 있다. 그때까지의 학습 기록은 남아 있다 |
